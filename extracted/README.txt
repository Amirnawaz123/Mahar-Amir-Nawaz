HOW TO RUN IN VS CODE
1. Open the "Amir_Nawaz_Portfolio" folder in VS Code.
2. Open index.html.
3. If you have Live Server installed, right-click index.html -> "Open with Live Server".
   Otherwise, double-click index.html to open it in a browser.
